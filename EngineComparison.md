Importing and placing files in Unity and Godot is basically the same for me. 
I think the biggest difference is that in Godot, everything must be bound under a node as a child object. 
The situation is different in Unreal Engine; when I import files, I have to set a series of settings individually (I clicked "Apply All," but for some reason it didn't work). 
For placing objects, all three engines allow me to drag content directly from the asset files into the scene, which I think is a great design.

I think there's a big difference between Prefab and Blueprint. Prefabs basically only handle structural things (I mean 3D models), while Blueprints include logic as well (blueprint logic). 
PackedScene confuses me a bit; a scene seems to be able to be anything.

If I had to do it again, I would probably still choose to use Unity for this, just like I said initially. Prefabs are very convenient; if I wanted to change the content to be implemented using prefabs, 
I wouldn't need to adjust any of the logic or worry about those things.
